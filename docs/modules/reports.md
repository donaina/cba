## Account Statement PDF

Generated by `StatementPdfService`:
1. Fetch transactions for date range
2. Fetch bank logo via `BrandingService.getLogoAsDataUri()` → base64 data URI
3. Build A4 HTML (logo top-left, Nigerian number formatting: ₦ symbol, `toLocaleString('en-NG')`)
4. Render via Puppeteer (headless Chrome, `--no-sandbox` in Docker)
5. Store in MinIO under `statements/{accountId}/{uuid}.pdf`
6. Return presigned URL (1-hour TTL)

**Logo in PDFs**: always embedded as base64 — never as a presigned URL.
Puppeteer cannot authenticate against MinIO at render time.
See [CLAUDE.md](../../CLAUDE.md) — rule #11.

If no logo is uploaded, the bank name renders as bold text instead.

## Trial balance

Queries `TransactionEntry` directly — not `Account.currentBalance`.
Correct accounting approach: balances derived from the entry ledger.

Results: GL code, account name, total debits, total credits, net balance.

---

## Loan portfolio report

Groups loans by `classification`:
- Count and aggregate outstanding principal per classification
- NPL ratio: `(WATCH + SUBSTANDARD + DOUBTFUL + LOST) / TOTAL`
- Total provision balance

Used for CBN MFB regulatory returns and internal credit risk monitoring.
